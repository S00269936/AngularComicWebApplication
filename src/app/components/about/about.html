About Comix App

Comix App is an Angular web application that lets users search for comic book characters, view detailed character information, and save favourites.

Character data is provided through the Comic Vine API and displayed using Angular components, services, routing, Bootstrap, and custom comic-book styling.

Features

  • Search comic characters
  • View character details
  • Browse results in card layout
  • Add characters to favourites
  • Load favourites from MongoDB
  • Backend API server using Express
  • Hosted on S3 + EC2
